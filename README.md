# 《美妆女王》互动影游 · 网页版 v4

纯原生 HTML5 响应式竖屏互动影游（零第三方框架与外部 CDN 依赖），支持手机（iOS Safari / 微信内置浏览器 / Android Chrome）与桌面端浏览器直接游玩。

## 1. 快速试玩与部署

### 本地启动（推荐带 HTTP 206 Range 支持）
```bash
cd "/workspace/大仓库/02_bots/antigravity 管家/2026-10-30/美妆女王_网页版_v4"
python3 serve.py 8080
```
浏览器打开 `http://127.0.0.1:8080/`（同一局域网手机可访问 `http://<本机局域网IP>:8080/`）。  
直接部署至 Nginx / Caddy / Apache / 静态托管平台时，仅需上传除 `serve.py` 外的纯静态资源即可。

## 2. 交互结构与剧情设计

严格遵循菱形汇流分支图（共 13 段 720×1280 30fps `faststart` 视频、4 个 5 秒限时选择点）：

```text
01-1.mp4 ──► [抉择1] ──► 02a-1.mp4 / 02b-1.mp4 ──► 03-1.mp4
03-1.mp4 ──► [抉择2] ──► 04a-1.mp4 / 04b-1.mp4 ──► 05-1.mp4
05-1.mp4 ──► [抉择3] ──► 06a-1.mp4 / 06b-1.mp4 ──► 07-1.mp4
07-1.mp4 ──► [抉择4] ──► 08a-1.mp4 / 08b-1.mp4 ──► 09-1.mp4（结局：救场女王）
```

- **5 秒倒计时**：每次抉择界面渲染上屏后启动 5.0 秒倒计时，超时默认自动选择 A；暂停或打开分支图时倒计时同步暂停。
- **回溯与存档**：每次进入节点自动写入 `localStorage` 存档；支持在结局、抉择栏、暂停菜单和「剧情分支图」中一键退回上一选择点（可从 `09` 依次退回 `07 → 05 → 03 → 01`，直接定位末帧重选）或重看本段。
- **结局成就**：采用《美妆女王》第 6 集 `S09-12` 官方文案——`达成成就：直播救场！职位晋升！` / `获得称号：救场女王`，置于下部安全区不遮挡人物面部。

## 4. 关键质量保障

1. **开头点击前绝对零声音**：
   - 首屏不挂载任何背景音乐或 `AudioContext`；`sessionActive === false` 期间全部 `<video>` 强制 `muted = true`、`volume = 0`、`autoplay = false`，并绑定 `play` 事件拦截守卫（未点开始前任何异常触发均立即静音并 `pause()`）。
   - 首屏仅通过 `.load()` 静默预缓冲 `01-1.mp4`，绝不调用 `.play()`。
2. **第一段视频严格 1.0 倍速原速播放**：
   - 弃用 Unity WebGL 的 `RenderTexture` 逐帧纹理上传与 `skipOnDrop = false` 阻塞模型，改用浏览器原生 `<video>` 硬件解码与 GPU 合成层直接渲染，播放期间零实时 Canvas 拷贝、零动态高斯模糊滤镜开销。
   - 在初始化、`loadedmetadata`、`canplay`、`playing`、`ratechange` 全生命周期强制锁定 `defaultPlaybackRate = 1.0` 与 `playbackRate = 1.0`。
   - **错峰预加载保护**：`01-1.mp4` 在首页已独占带宽预缓冲；点击开始后的前 `1.2 秒` 禁止任何后台分支预加载，确保首段起播独占网络与解码器，稳定播放后再顺序预载 `02a` 与 `02b`。

## 5. 已知浏览器策略与平台限制

- **iOS 内联播放与微信 WebView**：已声明 `playsinline`、`webkit-playsinline` 及 X5 同层属性 `x5-playsinline`、`x5-video-player-type="h5-page"`。在 iPhone Safari 与主流移动端浏览器中可保持页面内联播放与叠加选项 HUD；极少数老旧第三方 App 内置浏览器可能仍强制劫持原生全屏控件。
- **移动端有声自动播放策略**：移动浏览器要求有声播放必须源自用户交互手势。本引擎在用户点击「开始游戏」手势调用栈内同步解锁主槽音轨，并在后续顺播/超时跳转时优先复用已获手势授权（blessed）的视频槽；若极端环境下浏览器仍拦截有声自动起播，会自动降级为静音不中断播放并弹出顶部「点击开启原声」一键恢复条。
- **服务端 Range 请求要求**：iOS Safari 播放与回溯定位（Seek 末帧）要求 HTTP 服务器支持 `206 Partial Content`（如 Nginx、主流静态托管或附带的 `python3 serve.py`）。
